# PROJECT CR7 — prototyp PWA

## Uruchomienie
W folderze uruchom `python3 -m http.server 8000`, a następnie otwórz `http://localhost:8000`.

## iPhone
Umieść pliki w repozytorium GitHub i włącz GitHub Pages (Settings → Pages → Deploy from branch → main/root). Otwórz adres strony w Safari → Udostępnij → Dodaj do ekranu początkowego.

## Ważne ograniczenia
- To działający **prototyp offline-first**, nie pełny produkt.
- Plan tygodnia jest generowany z szablonu, **nie przez prawdziwy model AI**.
- Czat AI jest demonstracyjny. Aby dodać prawdziwe AI, potrzebny jest bezpieczny backend i klucz API przechowywany poza kodem przeglądarki.
- Zdjęcia ćwiczeń: obecnie link do wyszukiwarki grafik, nie osadzone licencjonowane zdjęcia.
- Dane są w localStorage: eksportuj kopię JSON w Profilu.
- Brak synchronizacji między urządzeniami, Apple Health i Apple Calendar.
- Wpisy i ciężary w szablonie to przykłady, nie spersonalizowane zalecenia treningowe.
